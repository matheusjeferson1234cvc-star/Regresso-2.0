# Bot de Tickets para Discord

Sistema profissional e completo de gerenciamento de tickets para Discord com suporte a modais e logs.

## 🚀 Como enviar para a Discloud

1. Baixe este arquivo `.zip`.
2. Abra o arquivo `.env` dentro dele e insira seu `DISCORD_TOKEN` e `CLIENT_ID`.
3. Suba o arquivo `.zip` diretamente na [Discloud](https://discloud.app)!
